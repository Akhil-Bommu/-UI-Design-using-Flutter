# Flutter and Dart – Learning Journey

## About

This repository documents my personal journey of learning and exploring **Dart and Flutter** through hands-on practice and implementation.

I started with the fundamentals of Dart and gradually explored Flutter's approach to building modern, responsive, and interactive applications. The repository will continue to grow as I learn, practice, and build.

## What I’m Exploring

* Dart programming fundamentals and language concepts
* Flutter widgets and UI development
* Layouts using `Row`, `Column`, `Stack`, and other widgets
* Responsive UI design for different screen sizes
* Navigation and named routes
* Stateless and Stateful widgets
* State management using `setState` and Provider
* Reusable custom widgets
* Themes and custom styling
* Forms, input handling, and validation
* UI animations and transitions
* REST API integration
* Fetching, handling, and displaying dynamic data

## Learning Approach

I’m following a practical, build-as-I-learn approach. Instead of focusing only on theory, I’m implementing each concept through small programs and UI-based projects to understand how Flutter works in real applications.

This repository serves as a record of that progress, with new implementations and improvements added as I continue learning.

## Goal

To build a strong foundation in Flutter and gradually become confident in developing clean, responsive, interactive, and API-connected applications.

## Tech Stack

* **Dart**
* **Flutter**
* **Provider**
* **REST APIs**

> This repository is a work in progress and will evolve alongside my learning.
